Token Radar ranks 226 pre-token protocols by the implied value of a token they may one day issue, measured from the snapshot's own figures: a market multiple calibrated on the protocols that already trade, seven-day TVL growth, age with no token, and chain reach. Every row carries an eight-step farm plan with costs and times; the dashboard is sortable and filterable, shows the model's full breakdown for each protocol, and includes a model sandbox.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
